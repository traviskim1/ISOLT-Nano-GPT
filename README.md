# ISOLT Nano-GPT

A small GPT-style language model (SentencePiece BPE tokenizer + 4-layer Transformer) trained on Marcel Proust's *In Search of Lost Time*. Everything is in `isolt_gpt.ipynb`.

**Data:** the training text is not included. Get a plain-text English translation of *In Search of Lost Time* (e.g. C. K. Scott Moncrieff's translation, several volumes of which are free on [Project Gutenberg](https://www.gutenberg.org/ebooks/author/1366)), join the volumes into one UTF-8 file, and save it as `isolt.txt` next to the notebook.
